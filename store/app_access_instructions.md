# App Access Instructions (for Play review)

The app requires **no login** and has **no backend** — reviewers can use it fully offline, immediately.

**To review all features:**

1. Open the app → onboarding (3 slides) → create any hero (name + class).
2. **Home:** tap "＋ Add Habit" → create a habit:
   - Title: "Morning Run", Type: "Workout (timed)", Duration: 10 min, Difficulty: Medium
   - Title: "Read Pages", Type: "Reading", Target: 20 pages
   - Title: "Drink Water", Type: "Simple (tap to check)"
3. **Workout:** tap "Start" on the workout habit → tap Start (timer runs, figure animates, reps count) → tap "Finish early" to see the rewards screen.
4. **Simple habit:** tap "Complete" — XP/gold are awarded, progress ring updates.
5. **Boss:** reaches unlock at level 2 (a few habit completions) → Home shows the boss teaser → Boss tab → tap Attack repeatedly to win. Hero HP drops; if it hits 0, tap Revive.
6. **Shop:** spend gold on items → they appear in Hero → Inventory as equipped.
7. **Quests:** Daily Quests tab shows progress from your habit activity; tap Claim when done.
8. **Calendar:** heatmap + 7-day chart update with each completion.
9. **Settings:** theme (light/dark), language (English/Hindi), notifications toggle, Delete all data (with confirmation dialog).
10. **Premium:** tap 💎 in More → on Android shows Play Billing; on web shows an honest "available in Android app" note.
11. **Offline test:** enable airplane mode — every feature still works.

**Test note:** All data is local; uninstalling the app erases everything.
